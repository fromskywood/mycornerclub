# My Corner Russian Uppercase Font Library

This set extends the My Corner hand-drawn uppercase style to the Russian alphabet.

## Alphabet

Russian uppercase letters included:

`А Б В Г Д Е Ё Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ъ Ы Ь Э Ю Я`

## Files

- `OPEN_THIS_COMPLETE_RUSSIAN-А-Я.svg` - main Russian uppercase set with the original loose wobble filter.
- `OPEN_THIS_COMPLETE_RUSSIAN-А-Я_SAFE.svg` - same set with expanded SVG filter area and visible overflow.
- `OPEN_THIS_COMPLETE_RUSSIAN-А-Я_NO_FILTER.svg` - same set without the wobble filter for the most reliable import behavior.
- `OPEN_THIS_COMPLETE_RUSSIAN-А-Я_THIN_SAFE.svg` - thinner Russian set with the wobble filter.
- `OPEN_THIS_COMPLETE_RUSSIAN-А-Я_THIN_NO_FILTER.svg` - thinner Russian set without the wobble filter.

## Notes

- The style follows the first, playful My Corner alphabet direction rather than the later cleaner correction.
- Shared Latin-like forms were reused where appropriate: `А`, `В`, `Е`, `К`, `М`, `Н`, `О`, `Р`, `С`, `Т`, `Х`.
- Cyrillic-specific letters were drawn as simple marker forms to match the same handmade rhythm.
